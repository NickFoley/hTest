# Playroom wall — 4150 × 2700

Design for the playroom north wall: toy bins below 910, book library above,
60" TV centred at 1070. All dimensions in millimetres from finished floor.

- `gen.js` — generator; all setting-out lives here as constants. `node gen.js`
  rewrites the two SVGs.
- `styled.svg` / `dims.svg` — elevation as built, and the dimensioned setting out.
- `playroom-wall.html` — the full design document (published as an artifact).
- `wall-elevation.png` — both drawings on one sheet.

Key setting out: bays 1100 / 1850 / 1100 with 50 scribes each end; bench 950;
door band 1750–2600; lower carcass 450 deep, upper 370.
